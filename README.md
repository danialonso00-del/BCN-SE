# BCN Sport Events — website

Single-page corporate site for BCN Sport Events (Dubai · Barcelona), built with React, Vite and TypeScript.

## Run

```bash
npm install
npm run dev        # development server → http://localhost:5173/
npm run build      # type-check and production build into dist/
npm run preview    # serve the production build → http://localhost:4173/
npm run build:map  # regenerate the dot map (public/map/dots.svg, src/data/map.json) — takes a few minutes
```

Requires Node 18 or later.

## Structure

```
index.html                 SEO, Open Graph, favicon, hero preload
public/
  brand/                   Logo (unchanged original + resized WebP) and icons cut from the monogram
  images/                  Graded, responsive WebP photography (see CREDITS.txt)
  map/dots.svg             Dot-matrix map (Natural Earth, generated by scripts/build-map.mjs)
  og-image.jpg             1200×630 social image
  CREDITS.txt              Author, source, licence and edits for every photo
src/
  styles.css               Design tokens (colours, type, easing) and all component styles
  App.tsx                  Section order
  content.ts               Services, needs and process steps (single source for all copy lists)
  components/              Header, Hero, About, Connection (map), Expertise, Applications, Approach,
                           Statement, Contact, Footer, plus Frame (animated image frame) and Icons
  three/stadium.ts         Line-drawn 3D stadium (Three.js), loaded on demand
  hooks/                   Scroll reveal and subtle parallax
LOGO.jpeg                  Original logo file as supplied
```

## Design notes

- **Colour.** Blue `#003A84` and burgundy `#A5023A` were sampled from the inside of the logo's letters, away from the JPEG edges. Blue carries structure (eyebrows, outlines, the Applications band). Burgundy carries actions (every CTA) and accents. On dark backgrounds a lifted burgundy (`#E0245E`) is used, only for large type and decoration.
- **Logo.** The original file is used as supplied, always on white, which is its own background. Over the hero it sits on a white plate, and the header turns fully white on scroll. It is not recoloured, blended or cut out.
- **Type.** Barlow Condensed for display and Inter for body text, both self-hosted through Fontsource.
- **Photography.** Stadium architecture leads the page: hero, About, Expertise and Statement. One people image (a team huddle) represents knowledge transfer. Every photo has the same cool, desaturated grade so the set reads as one series. The Statement roof uses a brand-blue duotone. No captions name a venue or suggest any project or relationship.
- **Motion.** The headline enters line by line, the stadium-plan linework draws itself in the hero, sections reveal on scroll, images wipe in, the Dubai→Barcelona arc draws, the process rail fills, and photos drift with very light parallax (fine pointers only). Under `prefers-reduced-motion` all of this is switched off and the content is shown in place. Content is never hidden if JavaScript fails.
- **3D.** The Contact section has an abstract stadium drawn in lines: tiers, rakers, a cantilever roof, and a burgundy pitch with a single lap marker. Three.js is fetched only as the section gets close to the viewport. Rendering pauses off-screen and in background tabs, pixel ratio is capped at 1.5, and the scene follows the pointer with easing. A static SVG drawing is shown instead when WebGL is unavailable, on low-memory or Save-Data devices, and before the scene loads. Under reduced motion a single still frame is rendered.
- **Accessibility.** One H1 with ordered headings, a skip link and visible focus styles. The mobile menu sets `aria-expanded`, traps focus, closes on Escape, a link click or resize, and returns focus to the toggle. Copying the email is announced through a polite live region.

## Sections

- **Expertise.** Five services: Football Academy, Training & Knowledge Transfer, Sports Event Organisation, Sports Infrastructure Optimisation, and Sports Business Development & Marketing. On desktop (≥1024px) they are accessible tabs: arrow keys, Home and End, roving tabindex. On smaller screens every service is shown stacked.
- **Map.** Dubai and Barcelona on a Natural Earth dot map, with Spain and the UAE highlighted.
  - Real city coordinates and the great-circle distance between the two cities.
  - The route is drawn in and a comet travels along it. Markers pulse, and the map tilts with the pointer.
  - Loops pause off-screen. The map is static under reduced motion.
- **What are you looking to build?** A bento grid whose tiles share a pointer spotlight. Each tile opens an email with a pre-filled subject.
- **How we work.** A sticky heading and step counter. A rail fills as the page scrolls and lights each step as it is reached, without taking over the scroll.
- **Icons and frames.** The line icons draw themselves in and loop subtly only on hover or while active. Image frames draw their outline, corners and scale, then a light sweep crosses the image.

## Before publishing

- Add `<link rel="canonical">` and `og:url` to `index.html` once the public URL is confirmed. Absolute URLs for `og:image` also depend on it.
- Review `public/CREDITS.txt`. Several images are CC BY or CC BY-SA and require attribution. The site links to the credits file from the footer.
- The Knowledge image shows an identifiable national team (Netherlands women's hockey team, Rio 2016). It is CC0, but consider replacing it.
